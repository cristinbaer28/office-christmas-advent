PLAYFUL OFFICE CHRISTMAS ADVENTURE — STARTER

Included:
- 12 customizable decorated-area screens
- Free exploration: tap any numbered stop to jump directly to it
- Music starts after the guest's first Play tap; later stop changes automatically attempt to play the next song
- Final Merry Christmas celebration screen
- Mobile-friendly playful Christmas styling

CUSTOMIZE:
Open index.html and edit the `const stops = [...]` list:
- area: name of the office location
- title: large screen heading
- message: short festive message
- song: displayed song title
- file: MP3 path
- emoji: decorative icon

Add permitted audio files to `audio/` named 01.mp3 through 12.mp3, or change the matching `file` paths.

PUBLISH:
Upload index.html and the entire audio folder to a GitHub repository.
Then open Settings > Pages, select Deploy from a branch, choose main and /(root), and save.
Create a QR code for the published URL.

AUDIO:
Mobile browsers require a user gesture before audio can begin. Guests tap Start the music once; subsequent navigation attempts to start the next song automatically. Some browsers may still require another tap after a pause or interruption.
Use recordings you have permission to stream. Commercial recordings may be copyrighted even if the underlying Christmas composition is public domain.

No database, login, tracking, or backend is required.
